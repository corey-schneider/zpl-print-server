🚀 Getting Started

What is ZPL Print Server?

ZPL Print Server is a web application that helps you print labels to Zebra thermal printers. It supports:

  • PDF uploads - Automatically converts PDFs to printer-compatible format
  • ZPL uploads - Upload pre-made ZPL files directly to your printer
  • Email automation - Automatically pulls labels from your email inbox
  • Smart power control - Optional integration with smart plugs for power management

⚙️ Setup & Configuration

  1. Open the Settings (⚙️ button in top-right)
  2. Go to the 🖨️ Printer tab
  3. Enter your printer's IP address (e.g., 192.168.1.111)
  4. Click Test Connection to verify
  5. Click Save Changes

Need to find your printer's IP? Check your printer's display panel or access your router's admin page.

  1. Go to Settings → 📧 Email tab
  2. Check the "Enable Email Polling" checkbox
  3. Enter your Yahoo Mail email address
  4. Create an app-specific password:
    • Visit your Yahoo Account Security
    • Generate a new "App password" (not your regular password)
    • Paste the generated password into the field
  5. Configure email filters (sender, subject, body keywords)
  6. Set check frequency (default: 60 seconds)
  7. Click Test Email Connection to verify
  8. Click Save Changes

💡 Tip: Use "all three" filters to prevent unwanted emails from being printed. For eBay, try: From: "ebay@ebay.com", Subject: "shipping label", Body: "ready"

If you have an expensive printer or want to save electricity, you can automatically turn your printer on/off based on print jobs.

  1. Get a smart plug (TP-Link, IFTTT-compatible, etc.)
  2. Go to Settings → ⚡ Smart Plug
  3. Check "Enable Smart Plug Integration"
  4. Enter webhook URLs for turning the plug ON and OFF
  5. Click Save Changes

Optional feature: You don't need this to use the printer. It's only for power savings.

📄 Uploading & Printing

  1. Go to the home page
  2. Drag & drop your PDF file into the upload zone, or click to browse
  3. The app will automatically:
    • Convert the PDF to ZPL format
    • Generate a preview image
    • Send it to your printer
  4. Check the jobs table below to see the status

Yes! If you already have a ZPL file (e.g., exported from design software), you can upload it directly.

  1. The upload zone accepts both PDF and ZPL files
  2. Just drop your .zpl file
  3. It will be sent directly to the printer without conversion (lossless)

💡 Pro tip: ZPL uploads are perfect for labels you've already designed and tested.

READY - File received, waiting to print
QUEUED - Printer is offline; job waiting for printer to come back online (will print automatically)
PRINTING - Currently sending to printer
COMPLETED - Successfully printed
FAILED - Error occurred (check the log for details)

🔧 Troubleshooting

Good news! Your job was received but the printer was offline. Instead of failing, the job is now queued and will automatically print as soon as the printer comes back online.

  1. Make sure printer is powered on and connected to the network
  2. Verify network connection: Check that the printer can be reached
  3. Wait a moment: The app polls for the printer every 10 seconds
  4. Job will auto-print: Once the printer is back online, queued jobs will print in order

💡 Tip: You can upload multiple labels while the printer is offline - they'll all queue up and print automatically when it comes back!

  2. Ping the printer: Open terminal and run ping 192.168.1.111 (use your printer's IP)
  3. Verify IP address: Go to Settings and double-check the IP is correct
  4. Check firewall: Ensure port 9100 is not blocked
  5. Restart printer: Power cycle the printer and try again
  1. Check if enabled: Go to Settings → Email and make sure "Enable Email Polling" is checked
  2. Verify credentials: Use the "Test Email Connection" button to verify your username and password
  3. Check filters: Emails must match all three filters (From, Subject, Body). Adjust them if needed
  4. Check frequency: Increase the check frequency to test (default is 60 seconds)
  5. App password: Make sure you're using an app-specific password, not your regular Yahoo password
  6. Check inbox: Verify the email is in your main inbox (not spam/trash)

This can happen when:

  • PDF dimensions don't match the label size (4x6 for Zebra GX420t)
  • PDF has unusual fonts or special characters
  • Image quality is very low in the original PDF

Solutions:

  • Try uploading a ZPL file instead (if you have one)
  • Check the PDF preview image in the jobs table
  • Adjust your PDF before uploading (proper dimensions, quality)

⚡ Advanced

PDF Files (.pdf)

Standard PDF documents - automatically converted to ZPL

ZPL Files (.zpl)

Zebra Programming Language files - sent directly to printer without conversion

Local Storage:

  • All files stored in /app/data/
  • Database (SQLite) at /app/data/printer.db

Security:

  • Email passwords are encrypted with an AES key stored in .env
  • No data is sent to external servers
